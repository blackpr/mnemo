# Answer-key audit log

Every question in `questions.jsonl` starts as a model draft with `audited: false`. An auditor (a
model in stage 2, `auditedBy: "model"`; a human when one does it, `auditedBy: "human"`) reads the
whole conversation, then either marks it `audited: true` (optionally correcting the key) or drops it.
Nothing is silently removed or rewritten: each change is logged here with the reason, so the
question set stays reproducible and the drop rate is known (LoCoMo-style flawed keys are what
this log exists to catch).

Format: one line per change, newest last.
